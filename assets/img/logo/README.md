# TrueNorth Living — logo files

The mark is a lit doorway with the north star cut out of it. The star is a
**hole**, not a shape — it shows whatever is behind the logo. That's why there's
no separate "reversed" version: the same file works on any background.

## Which file to send

| Situation | File |
|---|---|
| Anything on a dark background | `truenorth-horizontal-dark.svg` |
| Anything on a light background | `truenorth-horizontal-light.svg` |
| Square-ish space — social profile, sign, shirt front | `truenorth-stacked-*.svg` |
| Icon only, no words | `truenorth-mark.svg` |
| One-colour printing, embroidery, stamps | `truenorth-mark-ink.svg` (dark) or `truenorth-mark-white.svg` |

Send a printer or sign maker the **SVG**. It's vector, so it stays sharp at any
size from a business card to a building sign. If they insist on "a high
resolution file," the SVG *is* the high resolution file — say that.

## Colours

```
Amber   #E8A33D    the mark on dark backgrounds
Amber   #9C6413    the mark on light backgrounds (darker, for contrast)
Ink     #0C141C    text on light backgrounds
Bone    #F6F2E9    text on dark backgrounds
```

The two ambers are deliberate. `#E8A33D` on a white background is too light to
read at small sizes, so the light-background files use the deeper `#9C6413`.

## Rules worth keeping

- **Leave space around it.** Clear space on all sides should be at least the
  width of the doorway itself.
- **Don't recolour the star.** It's a hole. Filling it in kills the whole idea.
- **Don't stretch it.** Scale proportionally or not at all.
- **Don't put the amber mark on a mid-tone background.** It disappears. Use the
  ink or white version instead.
- **Minimum size:** about 16px tall on screen, 8mm in print. Below that the star
  closes up.

## Fonts in the lockups

The lockup files reference **Fraunces** (the "TrueNorth" wordmark) and **Inter**
("LIVING"). If a designer opens these and the text looks wrong, the fonts aren't
installed on their machine — both are free from Google Fonts. Ask them to
convert the text to outlines before printing and it stops mattering.

## Rejected directions

Two other marks were designed and set aside, in case you ever want to revisit:

- **Polaris** — the north star breaking through a compass ring. Elegant, but it
  read as generic at small sizes.
- **Homeward** — the star above a roofline. Warmest of the three, but the roof
  disappeared at favicon size.

Ask and they can be brought back.
